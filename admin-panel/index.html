Sincronização entre PDVs

Agrupe instalações do mesmo negócio (ex: duas caixas registradoras da mesma loja) pra elas somarem vendas juntas no relatório consolidado. Diferente do agrupamento por cliente — um cliente pode ter negócios diferentes que NÃO deveriam somar vendas juntos (padaria e restaurante, por exemplo); um grupo de sincronização é só pra terminais do MESMO negócio.

Visão geral do negócio

Somado de todas as instalações — só contagens, nunca o conteúdo de uma venda específica. Atualiza sozinho conforme os clientes ficam online (cada um manda o próprio número a cada 6h).

Erros reportados automaticamente

Quando o app quebra na máquina de um cliente, um relato técnico chega aqui — antes dele ligar reclamando. Só texto de erro/diagnóstico, nunca dado de venda ou cliente.

Mensagem na tela inicial

Aparece como um banner na tela inicial do app de todo cliente — pra avisos gerais, horário de feriado, ou uma imagem sazonal. Pra mensagem específica de UM cliente (ex: pendência), use o campo "Mensagem" dentro do bloco daquele cliente, na tela Painel.

Atualização obrigatória

Publique uma versão mínima obrigatória — todo cliente com versão mais antiga é bloqueado até atualizar, com download e barra de progresso automáticos. Use a versão exata que você acabou de publicar no GitHub Releases (ex: 0.5.0).

Quer testar uma versão só numa máquina antes de publicar pra todo mundo (ou isentar um cliente específico da regra global por um tempo)? Use o botão "Testar versão" no bloco daquele cliente, na tela Painel — isso vale só naquela máquina, sem afetar as outras.

Backups na nuvem

Cada instalação sobe uma cópia do próprio backup local pra nuvem sozinha (guarda os 10 mais recentes por máquina). Use "Pedir backup agora" se não quiser esperar o próximo automático, e "Restaurar" pra aplicar um backup de volta remotamente — a máquina do cliente reinicia sozinha em seguida, sem precisar de ninguém sentado lá.

Cofre de senhas

Acessos remotos (RDP, TeamViewer, AnyDesk...) e credenciais de admin dos servidores dos clientes. Cada senha é cifrada aqui no seu navegador com uma senha-mestra que só você sabe, ANTES de ir pro Firestore — sem essa senha-mestra, ninguém lê o conteúdo, nem quem tiver acesso ao projeto Firebase. Guarde bem a senha-mestra — não existe "esqueci minha senha" aqui, é só isso mesmo que protege os dados.

🎲 Gerador de senha aleatória

Só existe aqui na tela — nunca é salva sozinha em lugar nenhum. Some assim que você limpar, gerar outra, trocar de tela ou fechar essa aba. Pra guardar de verdade, use o botão "Gerar" dentro de um acesso (em "+ Novo acesso") e clique em Salvar.

Ainda não existe uma senha-mestra pra esse cofre — crie uma agora.

🌐 Contas Google vinculadas

Criadas pelo próprio app na tela Configurações → Backup de cada instalação. O e-mail sempre aparece; a senha só descriptografa aqui, com o cofre destravado — nunca passa em texto puro por fora deste navegador.

Ainda não existe uma chave de proteção pra contas Google — gere uma vez só (feito isso, os apps já conseguem proteger as senhas que forem salvando sozinhos).
